感染症週報ナビ 中継API

国立健康危機管理研究機構(JIHS)の感染症発生動向調査 週報(速報値)を配信する中継APIです。

エンドポイント

全データ(都道府県別 + 市区町村スポット)

GET /api/surveillance.json

APIを開く

レスポンス形式

{
  "version": "20260922162331",
  "generatedAt": "2026-09-22T16:23:31",
  "period": "2026年第29〜37週",
  "weekLabels": ["7/13", "7/20", ...],
  "prefectures": {
    "東京都": {
      "influenza": [[97, 0.23], [138, 0.33], ...]
    }
  },
  "spotlight": {
    "静岡市": { "influenza": [[4, 0.22], ...] }
  }
}

データの内容

  • prefectures: 47都道府県 × 8疾患。各値は [報告数, 定点当たり]（古い週→新しい週）。
  • spotlight: 静岡市・東京都中央区・京都市の市区町村別公式データ。
  • 更新: 毎週自動で最新週を取り込みます（未公開週は [0,0] 埋め）。

出典: 感染症発生動向調査 週報（速報値）/ 各自治体公表資料。速報値は後日修正される場合があります。
